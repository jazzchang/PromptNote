连接 Eagle 图库

请确保您的 Eagle 软件已在运行。
Eagle 会在本地启动 API 服务（默认端口 41595），我们需要检测并连接它。

⏳
等待检测...
点击下方按钮检测 Eagle 连接状态
连接失败？请检查以下几点：
  • Eagle 软件是否已启动？
  • Eagle 的 API 服务端口是否被占用？
  • 防火墙是否阻止了本地连接？
  • 如果是 Eagle 4.0+ 版本，需要填写 API Token
🔑

Eagle API Token（可选）

如果您使用的是 Eagle 4.0 或更高版本，需要填写 API Token 才能正常使用。
Token 可以在 Eagle 设置 → 高级 → API Token 中找到并复制。

💡 提示：较低版本的 Eagle 不需要 Token。如果不确定，可先留空并点击"跳过"。

配置完成！
